# 🦷 Abod - تطبيق ثني أسلاك تقويم الأسنان

تطبيق جوال متقدم للتحكم بآلة ثني أسلاك تقويم الأسنان عبر البلوتوث باستخدام React Native.

## ✨ المميزات الرئيسية

- 🎮 **التحكم بالآلة**: تشغيل وإيقاف وتحكم كامل بسرعة المحرك
- 📱 **اتصال البلوتوث**: اقترن بالآلة بسهولة وتتبع حالة الاتصال
- 📊 **إدارة المشاريع**: إنشاء وتحرير حذف المشاريع بكفاءة
- 🔧 **المعايرة**: معايرة تلقائية للآلة لضمان الدقة
- 📈 **السجل والإحصائيات**: تتبع كل العمليات والإحصائيات
- 🌍 **دعم العربية**: واجهة المستخدم بالكامل باللغة العربية
- 🎨 **تصميم حديث**: واجهة جميلة وسهلة الاستخدام
- ⚡ **أداء عالي**: تطبيق سريع وسلس

## 🏗️ البنية المعمارية

```
Abod/
├── app/
│   ├── navigation/
│   │   └── Navigation.js          # ملاح التطبيق
│   ├── screens/
│   │   ├── HomeScreen.js          # الشاشة الرئيسية
│   │   ├── ProjectsScreen.js      # إدارة المشاريع
│   │   ├── ProjectDetailScreen.js # تفاصيل المشروع
│   │   ├── MachineControlScreen.js# التحكم بالآلة
│   │   ├── BluetoothScreen.js     # إدارة البلوتوث
│   │   ├── CalibrationScreen.js   # معايرة الآلة
│   │   ├── SettingsScreen.js      # الإعدادات
│   │   └── HistoryScreen.js       # السجل والإحصائيات
│   └── redux/
│       ├── store.js               # متجر Redux
│       └── slices/
│           ├── projectsSlice.js   # حالة المشاريع
│           ├── machineSlice.js    # حالة الآلة
│           └── settingsSlice.js   # حالة الإعدادات
├── App.js                         # مكون التطبيق الرئيسي
└── package.json                   # المكتبات والتبعيات
```

## 📦 المتطلبات

- Node.js >= 16
- React Native >= 0.72
- Expo CLI (اختياري)

## 🚀 البدء السريع

### 1. التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/abodjamhour48-web/Abod-.git
cd Abod-

# تثبيت المكتبات
npm install
# أو
yarn install
```

### 2. التشغيل على Android

```bash
npm run android
# أو
react-native run-android
```

### 3. التشغيل على iOS

```bash
npm run ios
# أو
react-native run-ios
```

### 4. بدء خادم Metro

```bash
npm start
# أو
react-native start
```

## 🎯 الميزات المفصلة

### 🏠 الشاشة الرئيسية
- عرض حالة الآلة الحالية
- عرض آخر المشاريع
- روابط سريعة للإجراءات الرئيسية
- عرض مستوى البطارية

### 📁 إدارة المشاريع
- إنشاء مشاريع جديدة
- عرض قائمة المشاريع
- تحرير تفاصيل المشروع
- حذف المشاريع
- عرض الإحصائيات

### 🎮 التحكم بالآلة
- التحكم بسرعة المحرك (0-100%)
- عرض حالة الآلة
- أزرار تشغيل/إيقاف مؤقت/إيقاف
- عرض تقدم الثني
- خيارات المعايرة والصيانة

### 📡 البلوتوث
- فحص الأجهزة المتاحة
- عرض قوة الإشارة
- الاتصال والقطع
- تاريخ الأجهزة المقترنة

### 🔧 المعايرة
- معايرة تلقائية للآلة
- عرض تقدم المعايرة
- خطوات معايرة واضحة
- نصائح مهمة

### ⚙️ الإعدادات
- اختيار اللغة
- تغيير المظهر (فاتح/غامق)
- التحكم بالإشعارات
- تفضيلات المستخدم
- معلومات التطبيق

### 📊 السجل والإحصائيات
- عرض سجل العمليات
- إحصائيات شاملة
- ساعات التشغيل
- عدد المشاريع

## 🛠️ التكنولوجيات المستخدمة

### Frontend
- **React Native** - بناء تطبيقات جوال
- **Redux Toolkit** - إدارة الحالة
- **React Navigation** - الملاحة بين الشاشات
- **React Native Vector Icons** - أيقونات جميلة

### أدوات التطوير
- **Babel** - محول جافاسكريبت
- **Metro** - منصة بناء React Native
- **Jest** - اختبار الوحدات
- **ESLint** - فحص الكود
